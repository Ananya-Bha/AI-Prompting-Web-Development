# WHAT MY QUIZ HAS
This is an interactive coding quiz webiste called 'Wired Up Quiz' using HTML, JavaScript, and CSS.

The quiz should have 3 main sections:
(A) Start Screen:
The start screen introduces the quiz and has a START button. When the user clicks the start button, the quiz begins and the first question screen appears.
The start screen shoukd include:
-the title: WIRED UP QUIZ
-a subtitle: 7 questions on Javascript, html and css
-a code themed graphic or code block area
-small html, css and js badge-style decorations/icons
-a large round start buttton

(B) Question screen
The question screen shoudl show one question at a time. 
Each question should include:
- a questions number
- a small section for extra infomation or instuction
- a dark rounded code display box where code snippet can be shown if the question needs so
- four muliple choice answer boxes
- a next button to move onto the next question
The quiz should track: 
- the current question 
- the user'd seleted answer

(C) Results screen\
The results screen should show the user’s final score.

It should include:
-The title: QUIZ COMPLETE
-Text saying: You scored:
-The final percentage score
-The number of correct answers out of 7
-A Review Answers button
-A Back to Home button
-Optionally, a Try Again button to restart the quiz

The Back to Home button should return the user to the start screen
The Review Answers button should allow the user to see each question, the correct answer, and what they chose.
