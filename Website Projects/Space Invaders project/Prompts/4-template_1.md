1. Features:
These are the main charcters that are involved in the game:
-> The enemy sprite: enemy.png
-> The player sprite: player.png
-> The bullet sprite: bullet.png
For the characters, use the png images saved in the assets folder of this project folder.

Each character in this game has a different function and purpose.

-> Player sprite: This is the main sprite which the user controls. It has its own baseline at which it starts at the beginning of every game. The player sprite can move sideways on the same y axis coordinate. Meaning they can change their x positions when the user presses their sideways arrows.
-> The bullet sprite: this is the sprite which the bullet uses to chooses the enemny sprites. It should project out of the player sprite when the user presses their space bar, and shoots upwards from the position of the player.
