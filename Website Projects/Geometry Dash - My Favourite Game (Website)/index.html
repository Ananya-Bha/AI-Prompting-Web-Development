Geometry Dash

Jump, Dodge, and Groove to the Beat!

Learn About the Game

Geometry Dash is a rhythm-based game, where players control a jumping icon to navigate through music-synced levels filled with different types of obstacles.

Features

Platforming Action

Players primarily jump to avoid obstacles like spikes and hazards. (Fantasy)

Rhythm-Based Movement

The game's pace and your movement is influenced by music, creating a rhythmic flow. (Sensation)

Icon Customization

By completing checkpoints in levels, players can collect game currency to unlock different icons, and customization options for their character. (Discovery)

Create Your Own

Players can create and navigate through their own levels which they can add obstacles to to vary difficulty for themselves and others. (Expression, Fellowship)

Personal Thoughts

  • It's a fun, eye-catching game that always keeps me invested.
  • Levels are easy but challenging at the same time so they keep the user focused and time flies by. (Challenge)
  • It has a practice mode, through which the players can practice playing the levels, without having the need to start from the beginning each time.
  • The musical aspect is very soothing and is perfectly synced with each time a player should make a move in the game, which is great for assistance. (Sensation)
  • The music changes each level so it's not boring.
