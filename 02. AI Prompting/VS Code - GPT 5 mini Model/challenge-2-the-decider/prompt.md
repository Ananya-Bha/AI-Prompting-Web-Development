# Prompt

## Describe how the app works
This website is a "Decider" website, in which the user can enter 3 options (A,B,C) and ask the website which one it should choose depending on their fate. The Website should be able to pick a random option amongst the 3 choices available to it from the user. When the user presses the "DECIDE' button, the website should show which option has been picked.

## Describe the style
The style of this webiste should be simple, with pastel clean colours. 
This is the main structure:
1 Bold heading, aligned to the left of the website page - "The Decider"
2. Subtitle which says "Can't Choose? Let fate decide." aligned to the left below the title
3. The 3 input fields, one for each option the user can enter
4. The DECIDE button whihc pormpts the website to choose an option and show it to the user
