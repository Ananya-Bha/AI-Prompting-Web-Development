# Prompt

## Describe how the app works
This webiste is an exam score grader website, in which the user can enter their exam score (number out of 100) and recieve a comment based on their marks. These are the cut-offs and the comments for each specific group of marks:
1.40 or below: CATASTROPHIC. We must speak with your parents
2.  60 or below but above 40: Acceptable. You will not be expelled this time.
3. 85 or below, but above 60: Somewhat Good. Atleast you tried your best.
4. 95 or below, but above 85: Great Job. You're basically perfect!
5.Above 95: Seems a bit suspicious...

## Describe the style
This website should have a simple and proffesional style, with tones of blue and green. There should be the following:
1. Bold title: "The Exam Grader" centered to the left of the website page
2. Subtitle aligned to the left as well which says "Type a score. Hear the verdict"
3. Input field- where the user enter their grade
4. GRADE button, which prompts the website to respond accordingly depending on the user's grade.
