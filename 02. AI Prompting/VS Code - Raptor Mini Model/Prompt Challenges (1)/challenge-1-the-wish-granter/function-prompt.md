# Prompt

## Describe how the app works

This app is a wish granter app, in which the cosmos decides if the user's wish is granted or not. It is called "The Wish Granter". 

The website has a clean, simplistic style with an input field that allows the user to enter what they want to wish for, after pressing the "GRANT" button, the app lets the user know wether their wish has been granted or not.

If the wish has been granted, the app should show - "WISH HAS BEEN GRANTED"
If the wish has not been granted, the website should show - "WISH DENIED"

The structure of the website is as follow:
1.H1 heading with the title
2.Subtitle which says " Make a wish.The cosmos decides."
3.Input field and GRANT button side by side
4.Display showing if the wish has come true or not.
