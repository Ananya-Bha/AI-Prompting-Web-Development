## Describe how the app works
This webiste is called "The Mood Doctor". It is designed for helping the user get diagnosed and prescribe a certain phrase to them. The user gets the option to enter the follwoing words : sad, tired, happy, angry, bored. As a reply, the user should recieve a saying prompted by the website to make them feel better. Here are the follwoing sayings:
1. sad- Watch a sunset. Eat ice cream. Repeat tomorrow.
